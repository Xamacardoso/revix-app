# Capturas de tela

Use esta pasta para capturas verificáveis do aplicativo executando em dispositivo ou emulador. Não substitua imagens reais por wireframes; os wireframes de referência ficam em `../design/`.

## Nome dos arquivos

Use nomes descritivos como:

- `android-garagem-listagem-rapida.png`
- `android-cadastro-motocicleta.png`
- `android-detalhes-historico.png`
- `ios-garagem.png`

Registre no pull request ou no changelog a plataforma e o fluxo capturado. Remova ou oculte placas, dados pessoais e informações identificáveis antes de guardar capturas no repositório.
