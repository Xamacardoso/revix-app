# Checklist de entrega

- [ ] `flutter pub get` conclui sem erro.
- [ ] `dart format lib test` não deixa arquivos sem formatação.
- [ ] `flutter analyze` conclui sem problemas.
- [ ] `flutter test` passa, incluindo migrações SQLite e principais fluxos de interface.
- [ ] O change OpenSpec correspondente valida e seus requisitos foram revisados.
- [ ] Ícones, fonte e assets necessários são locais e carregam sem conexão.
- [ ] Validar instalação e abertura no alvo Android disponível; registrar quando o teste físico/emulador estiver pendente.
- [ ] Para iOS, gerar e validar em macOS/Xcode antes de declarar suporte executado.
- [ ] Atualizar `docs/CHANGELOG.md` com mudanças relevantes.
